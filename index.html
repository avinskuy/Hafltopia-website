How to Play

Please select the application you want to use!

📱 Halftopia Mobile APK

  1. Uninstall Real Growtopia if you have it
  2. your device (optional but recommended)
  3. Install Halftopia APK
  4. Open Halftopia APK & login with your account

🟢 PowerTunnel (Android)

  1. Install PowerTunnel APK
  2. Open → Plugin → Hosts → Open the Setting
  3. Enter: https://gtpshosting.web.id/raw/Halftopia
  4. Back, click "CONNECT", open Growtopia

🪟 Windows (Hosts Edit)

  1. Press Win+R → paste: C:\Windows\System32\drivers\etc
  2. Open hosts file with Notepad (Run as Admin)
  3. Add these lines at the bottom:
134.209.100.90 www.growtopia1.com 134.209.100.90 www.growtopia2.com
  1. Save the file → launch Growtopia

📊 Surge 5 (iPhone)

  1. Install Surge 5 from App Store
  2. Import Profile: https://gtpshosting.web.id/ios/Halftopia
  3. Allow VPN Configuration → Connect → Open Growtopia
